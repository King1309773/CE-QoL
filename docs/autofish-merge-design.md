# CE QoL 1.1.0：合入自动钓鱼

用户明确要求把自动钓鱼继续并入当前合并版。采用现有 stablefix2 逻辑作为第五个客户端模块，仍只有一个 ceqol 身份和一份安装 JAR。

- 完整保留真正咬钩声驱动、确认鱼漂移除后的延迟抛竿、超时/会话清理与无后台线程行为。
- 保留原按键身份、反斜杠默认键及资源命名空间；统一设置页增加筛选该按键的入口。
- 移除独立 AutoFish 入口，模块初始化和按键注册防重复。其他四个模块的生命周期与规则不变。
- 上游作者与许可证事实保留，独立 JAR 不嵌套；成品中只加入明确的 AutoFish 模块类。
- 先验证旧合并版缺少自动钓鱼按键的真实客户端 RED；新成品通过原 430 项测试、33 项真实处理器回归和实际客户端注册/界面检查后，再备份安装旧合并版与独立 AutoFish。
